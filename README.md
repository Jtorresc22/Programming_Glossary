# Programming_Glossary
Un glosario de términos y conceptos clave de programación explicados de forma clara y concisa. Diseñado como una guía de referencia rápida para desarrolladores, estudiantes y entrevistas técnicas.

# Glosario de Programación - 200 Términos Clave (MoureDev Pro)

Guía de referencia rápida en español que recopila y define de forma clara y accesible los **200 conceptos y términos más utilizados en el desarrollo de software y la programación moderna**.

### Contenido y Temáticas
Este glosario abarca desde los fundamentos esenciales hasta conceptos avanzados de arquitectura e infraestructura:

- **Fundamentos de Programación:** Algoritmos, variables, estructuras de control (loops, condicionales), tipos de datos y gestión de memoria.
- **Paradigmas de Software:** Programación Orientada a Objetos (POO), programación funcional e imperativa.
- **Desarrollo Web & APIs:** REST, GraphQL, Endpoints, HTTP/HTTPS, WebSockets, Frontend y Backend.
- **Bases de Datos & Persistencia:** SQL, NoSQL, ORM, Esquemas y normalización.
- **Arquitectura & Infraestructura:** Microservicios, Cloud Computing, Contenedores, CI/CD, DevOps y Seguridad (OAuth, JWT).
- **Herramientas & Control de Versiones:** Git, GitHub, entornos IDE, Linters y Testing (Unit Tests, QA).
